# Exemplo: piloto Estúdio

O Estúdio foi a demanda usada para observar a equipe em ação. O Builder encaminhou a definição para Produto, a direção visual para Design e a arquitetura para Engenharia. Qualidade e Segurança revisaram o material.

O exemplo serve para demonstrar o fluxo de coordenação. O código completo do piloto não é o foco deste repositório.
