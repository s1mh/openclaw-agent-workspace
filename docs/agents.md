# Equipe de agentes

| Agente | Papel | Entrega principal |
|---|---|---|
| `builder` | Coordenação | estrutura a demanda e distribui o trabalho |
| `produto` | Produto | problema, público, jornadas e critérios |
| `design-produto` | Design de produto | fluxos e interface |
| `design-marca` | Marca | direção visual e linguagem |
| `engenharia` | Engenharia | arquitetura, código e integração |
| `qualidade` | Qualidade | revisão independente e evidências |
| `infosec` | Segurança | riscos, limites e proteção de dados |
| `plataforma` | Plataforma | operação, ambiente e recuperação |
| `dados-metricas` | Dados | métricas e instrumentos de análise |
| `marketing-growth` | Marketing | posicionamento e experimentos |
| `comercial-atendimento` | Comercial | demonstração, onboarding e feedback |
| `financas-operacoes` | Finanças | custos e viabilidade |
| `legal-privacidade` | Jurídico | privacidade e limites de uso |

`main` é o ponto de entrada do workspace, não uma especialidade.
