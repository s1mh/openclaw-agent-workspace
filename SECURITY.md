# Segurança

Não publique tokens, senhas, cookies, chaves OAuth, arquivos `.env`, bancos, logs com dados pessoais ou configurações completas do gateway.

Use `.env.example` com valores fictícios e mantenha credenciais fora do repositório. Antes de publicar alterações, procure por padrões como `token`, `secret`, `api_key`, `password`, `authorization` e URLs privadas.

Os exemplos deste repositório descrevem a arquitetura. Eles não autorizam acesso a serviços externos nem devem ser usados para copiar credenciais entre agentes.
