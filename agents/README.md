# Perfis reais dos agentes

Os arquivos `AGENTS.md` deste diretório foram preparados a partir das instruções de função que estavam nos workspaces ativos da instalação OpenClaw do autor. Mantêm a especialidade e os métodos centrais de cada papel; são uma edição de portfólio, não cópias integrais da configuração operacional.

Foram removidos caminhos da VM, nomes de projetos privados, detalhes de contas e integrações específicas, referências a ferramentas internas, contexto de usuário e instruções temporárias de tarefas. O `IDENTITY.md` da instalação era principalmente o modelo padrão do OpenClaw, e por isso não é apresentado como uma identidade personalizada. As instruções compartilhadas foram resumidas em [TEAM-CONTRACT.md](TEAM-CONTRACT.md).

Para adaptar um papel, combine o respectivo `AGENTS.md` com as políticas, ferramentas, limites e permissões realmente configurados no seu próprio ambiente. Um arquivo de instruções, sozinho, não cria um agente nem garante acesso a ferramentas.
